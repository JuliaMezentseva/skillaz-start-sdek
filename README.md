# Прототип Skillaz Start для СДЭК

Демо-прототип модуля адаптации, наполненный контентом под действующего клиента.
План менеджера по привлечению клиентов на 90 дней: маршрут по этапам СДЭК,
три цели на испытательный срок, оценочные листы для проверки промежуточных
результатов, контрольные точки и риски.

Сценарий встречи — в `sdek-meeting-script.html` (лежит уровнем выше, рядом
с прототипом). Методика и обоснование решений — в [METHOD.md](METHOD.md).

> Все данные в прототипе — демонстрационные. Имена сотрудников, контакты,
> показатели и названия подразделений вымышлены и не отражают реальные данные
> клиента.

## Проверка страниц

`test/render-check.js` прогоняет HTML-страницу через Babel и рендерит её в jsdom
через настоящий React 18, проверяя, что `#root` не пустой и не было JS-ошибок.

### Установка (один раз)

```
npm install jsdom @babel/core @babel/preset-react react@18.3.1 react-dom@18.3.1
```

### Запуск

```
node test/render-check.js employee/plan.html
node test/render-check.js manager/plan.html --query "employee=irina"
```

Известные ограничения харнесса (унаследованы от исходного прототипа, не связаны
с контентом СДЭК): `hr/vacancy-new.html` не рендерится в jsdom — страница
использует `IntersectionObserver`, которого в jsdom нет; часть `interaction-*.js`
содержит устаревшие ассерты.
